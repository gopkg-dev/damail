DaMail 把多个邮箱（QQ、163、Gmail、Outlook、iCloud、企业邮……）集中同步到**你自己的服务器**上，在网页上统一收发和整理，并通过 **MCP** 和 **REST API** 安全地交给 AI Agent 使用。

名字读作「哒咩」（日语 だめ，“不行”）：没有你点头（逐封批准，或亲手授予 `send` 权限），Agent 一封信也发不出去。

## 它解决什么问题

  <Card title="邮箱太多" icon="email">
    工作、个人、项目各一个，来回切换客户端。DaMail 把它们合并成一个收件箱，回复时自动用对应的邮箱发出。

  <Card title="想让 AI 帮忙，又不放心交出账号" icon="approve-check">

## 主要功能

| 模块 | 内容 |
|---|---|
| 同步与阅读 | IMAP IDLE 实时推送、会话归并、跨文件夹去重、中文编码与中文搜索、HTML 邮件沙箱渲染 |
| 写信与整理 | 富文本写信、签名、延迟发送可撤销、定时发送、草稿审批、订阅管理，操作回写到邮箱服务器 |
| AI 功能 | 邮件分析、分类与标签、AI 搜索、AI 助手、邮件翻译、用量与费用统计 |
| 自动化 | 收信规则、通知渠道、日报周报、数据统计、等回复与跟进提醒 |
| 开放接口 | MCP（Streamable HTTP）、REST API、API Key 权限与邮箱范围、MCP OAuth（ChatGPT、Claude Duet、Grok Bot、Meta Muse 等）、Webhook |

## 架构

DaMail 是一个 Node.js 服务加一个 PostgreSQL 数据库，打包成一个 Docker 镜像：

- **服务端**：Hono + Drizzle ORM + imapflow，负责同步、发信、AI 任务队列、MCP 和 REST API
- **网页**：React + Ant Design，构建后由服务端直接提供
- **数据**：邮件索引和设置在 PostgreSQL，原始邮件和附件在数据目录；邮箱凭证用 `MASTER_KEY` 加密
